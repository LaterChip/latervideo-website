LaterVideo 是一个基于 WinUI 3 + C# 的 Windows 桌面「多媒体文件暂存与预览」工具——把图片、音乐、视频、文本、配置文件拖进来集中管理，就地预览，随手打开。

功能一览

一个窗口，管理你所有待处理的文件

导入、分类、预览、打开——所有操作都停留在列表层面，绝不触碰磁盘上的原始文件。用最少的操作，把「稍后再看」变成「随手就办」。

核心

拖拽导入

把文件或整个文件夹直接拖到窗口任意位置即可导入，文件夹自动递归展开，单次最多 5000 个文件。

自动分类

按扩展名自动归类为图片、音乐·音频、视频、文本、配置文件、文档与其他，右侧下拉框一键筛选。

实时搜索与排序

按文件名或完整路径实时搜索；按名称、大小、修改时间升降序，或按类型分组排序。

图片预览

选中即在右侧内嵌显示图片，无需打开外部程序。

文本 / 配置预览

内嵌只读文本框预览，自动识别 UTF-8 与 BOM；大于 10 MB 或含二进制特征时安全跳过。

音视频内嵌播放

内置播放器，支持播放、拖动进度、调节音量——音频视频就地预览。

打开 / 定位 / 复制路径

用系统默认程序打开、在资源管理器中定位选中、或一键复制完整路径到剪贴板。

只操作列表，不删文件

移除选中、清空列表只会把条目从列表拿掉，磁盘上的原始文件永远安全。

实时统计

底部状态栏实时显示文件总数、总大小、各分类数量与当前筛选后的结果。

为什么是它

把「找文件、确认内容」压缩成一次拖拽

当文件散落在多个文件夹、下载目录和聊天记录里时，LaterVideo 用一个窗口接管所有「稍后再看」——就地预览，处理完就移除，磁盘文件始终保持安全。

用了 LaterVideo

工作流

从导入到打开，只需四个动作

LaterVideo 把所有文件管理收敛成一条顺手的链路，每一个步骤都可以即时完成、随时中断。

第 1 步

1拖入文件

把文件或整个文件夹拖到窗口任意位置，出现半透明遮罩提示，松手即导入。文件夹自动递归展开，单次最多 5000 个文件，重复拖入自动去重。

第 2 步

2自动分类

按扩展名自动归入 7 大类，右侧下拉框按分类筛选，顶部搜索框按文件名或路径实时过滤，排序支持名称、大小、修改时间与类型分组。

第 3 步

3就地预览

选中即预览：图片直接显示；文本与配置以只读文本框呈现（自动识别 BOM）；音频视频内嵌播放器播放、拖动进度、调音量。

第 4 步

4打开 / 收尾

双击用系统默认程序打开，或右键定位在资源管理器中选中、一键复制完整路径。处理完的条目可从列表移除——磁盘文件永远安全。

构建与运行

本地编译，直接开跑

环境要求：Windows 10 1809（17763）及以上 / Windows 11、Visual Studio 2022 或 2026、.NET 8 SDK。打开解决方案，切到 x64 平台，F5 即可。

1

打开 Visual Studio

菜单 文件 → 打开 → 项目/解决方案，选择 LaterVideo.sln。

2

还原 NuGet 包

首次还原会自动下载 Microsoft.WindowsAppSDK；若未自动还原，右键解决方案 → 「还原 NuGet 包」。

3

切换平台为 x64

把解决方案平台从 Any CPU 切换为 x64（WinUI 3 需要具体平台）。

4

按 F5 启动

点击 ▶「LaterVideo (Unpackaged)」即可运行，直接看到应用窗口。

PowerShell · 命令行运行（可选） 
# 编译
dotnet build LaterVideo.csproj -c Debug -p:Platform=x64

# 直接运行
.\bin\x64\Debug\net8.0-windows10.0.19041.0\win-x64\LaterVideo.exe

# 发布单机版（可选）
dotnet publish LaterVideo.csproj -c Release -p:Platform=x64 -r win-x64 --self-contained true
